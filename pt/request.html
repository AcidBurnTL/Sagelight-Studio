Studio · trabalho à medida

Uma app pequena,a partir do que descrever.

A Sagelight Studio faz as suas próprias apps para iPhone e Mac, com os dados a ficar no dispositivo. Esta página é para outra coisa: uma app pequena para si, para a sua equipa ou para um cliente seu.

Descreva o que a app deve fazer, para quem é e se deve correr no iPhone, no Mac ou nos dois. Se o trabalho cabe numa app pequena, a Sagelight pode fazê-la. Isso só começa depois de acordarmos os requisitos e o âmbito por e-mail. Um rascunho aberto nesta página não é uma aceitação, nem um contrato, nem um lugar reservado.

O preço depende das especificações. Falamos dele à parte, por e-mail, quando o trabalho estiver claro o suficiente. Esta página não mostra preços, quantias nem tabelas. Não envie dados de pagamento, palavras-passe nem cópias de documentos de identificação.

Os pedidos vão para este endereço:

contact@sagelight-studio.com

É este o endereço do rascunho. O site não guarda o formulário nem envia o e-mail por si.
