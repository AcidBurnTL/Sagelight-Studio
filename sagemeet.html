Questions

Things people ask first.

Is SageMeet free?
Yes — SageMeet is free on the App Store. You provide your own OpenAI API key for AI features (Whisper transcription and GPT-4o summarization), so you pay OpenAI directly for usage rather than paying a subscription to us.
Does SageMeet send my audio to OpenAI?
Only when you explicitly run an AI feature (transcription, summarization, semantic search) and only via your own OpenAI API key. Recording itself is fully local. Private Mode disables every external request, so you can use SageMeet purely as a local recorder if you prefer.
What is BYOK?
Bring Your Own Key. Instead of a subscription, you bring your own OpenAI API key. The key is stored in the iOS Keychain and only used to authenticate requests you initiate. We have no backend, so we cannot bill you.
Does OpenAI use my recordings to train its models?
No. OpenAI's API terms explicitly state that data sent via the API is not used for model training. OpenAI is also certified under the EU-US Data Privacy Framework.
Where are recordings stored?
Recordings, transcripts, and AI-generated notes live on your iPhone, with optional iCloud sync to your other Apple devices. Sagelight Studio never receives or stores any of your meeting data.
What is Private Mode?
Private Mode is a single toggle that disables all external API calls. Recording, local playback, and on-device organization continue working — but no audio, text, or metadata leaves your device.
