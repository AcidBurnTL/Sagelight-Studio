Una app pequeña,a partir de lo que cuentes.

Sagelight Studio publica sus propias apps para iPhone y Mac, pensadas para que los datos se queden en el dispositivo. Esta página es para otra cosa: una app pequeña para ti, para tu equipo o para un cliente tuyo.

Cuenta qué debería hacer la app, para quién es y si va en el iPhone, en el Mac o en los dos. Si el trabajo cabe en una app pequeña, Sagelight puede hacerla. Eso empieza solo después de acordar por correo los requisitos y el alcance. Un borrador abierto desde esta página no es una aceptación, ni un contrato, ni un sitio reservado.

El precio depende de las especificaciones. Lo hablamos aparte, por correo, cuando el trabajo está lo bastante claro. Esta página no muestra precios, importes ni tarifas. No envíes datos de pago, contraseñas ni copias de documentos de identidad.

contact@sagelight-studio.com
