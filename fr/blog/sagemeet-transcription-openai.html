Transcrire une réunion sur iPhone : ce qui reste sur le téléphone et ce qui part chez OpenAI

En bref : dans SageMeet, la réunion est enregistrée et conservée sur l’iPhone. La transcription, le résumé et la recherche par le sens passent pourtant par OpenAI. Pour elles, l’audio ou le texte part chez OpenAI, avec votre propre clé d’API, seulement quand vous lancez une fonction d’IA. Rien ne part vers Sagelight. Si vous voulez que rien ne sorte du téléphone, vous activez le Mode privé. Plus bas, vous voyez quelles données vont où, et ce qu’OpenAI dit en faire.

Une réunion enregistrée peut contenir des choses que vous ne diriez pas en public : des chiffres, des noms, des décisions, parfois des problèmes personnels. C’est pour cela qu’il vaut la peine de savoir exactement par où passe chaque morceau.

Ce qui reste sur l’iPhone

L’enregistrement lui-même est local. SageMeet enregistre le son sur l’iPhone, en fichier M4A, sans streaming et sans envoi.

Restent aussi sur le téléphone :

  • les enregistrements, les transcriptions et les notes générées ;
  • l’index pour la recherche par le sens, dans une base SQLite locale ;
  • votre clé OpenAI, dans le Keychain iOS.

SageMeet lit aussi le calendrier, pour savoir de quelle réunion il s’agit. L’accès est en lecture seule : l’application ne modifie rien dans le calendrier.

Sagelight Studio n’a pas de serveur pour SageMeet. Nous ne recevons ni les enregistrements, ni les transcriptions, ni votre clé. L’application ne collecte pas non plus de statistiques d’usage ni de rapports d’erreur.

Ce qui part chez OpenAI, et quand

Les fonctions d’IA de SageMeet tournent sur les serveurs d’OpenAI, pas sur le téléphone. La politique de confidentialité les énumère toutes :

  • La transcription. L’audio part vers Whisper, le service de transcription d’OpenAI, et le texte revient sur l’iPhone.
  • Le résumé. Le texte de la réunion part vers GPT-4o, qui rédige le résumé, les décisions et les actions à faire.
  • La recherche par le sens. Le texte est envoyé pour être transformé en vecteurs. Les vecteurs sont ensuite conservés localement.
  • L’analyse des intervenants. Le temps de parole et la participation sont calculés par GPT-4o-mini.

La règle sur la page SageMeet est simple : l’audio et le texte partent chez OpenAI seulement quand vous lancez une fonction d’IA. Avant d’utiliser les fonctions d’IA, l’application vous demande votre accord pour le traitement par OpenAI.

Si vous ne voulez pas que l’audio d’une réunion précise parte chez OpenAI, activez le Mode privé avant d’enregistrer.

Les données circulent par internet. L’infrastructure d’API d’OpenAI est aux États-Unis, donc une transcription est un transfert de données hors de l’UE.

Votre clé, votre compte

SageMeet utilise le modèle BYOK (Bring Your Own Key) : vous apportez votre propre clé d’API OpenAI. Les requêtes partent directement de l’iPhone vers OpenAI, authentifiées avec votre clé. La clé reste dans le Keychain iOS et ne nous parvient pas.

Cela a deux conséquences pratiques :

  • Le coût. L’application est gratuite. Vous payez directement OpenAI selon votre usage, sans abonnement chez nous. Vous voyez la consommation dans votre compte OpenAI.
  • La relation avec OpenAI. Vous utilisez l’API OpenAI par votre propre compte, pas par un compte à nous. Les règles d’OpenAI pour l’API s’appliquent aux données envoyées.

Vous saisissez la clé dans l’application avant d’utiliser les fonctions d’IA.

Ce qu’OpenAI fait des données envoyées par l’API

Nous avons lu la documentation d’OpenAI, pas seulement ce que nous disons sur le site. En bref :

  • L’entraînement des modèles. OpenAI écrit que, depuis le 1er mars 2023, les données envoyées par l’API ne servent pas à entraîner ni à améliorer les modèles, sauf si vous choisissez explicitement de les partager.
  • La conservation temporaire. OpenAI peut conserver les données envoyées par l’API jusqu’à 30 jours, pour détecter les abus. Ensuite, il les supprime, sauf si la loi lui demande de les garder plus longtemps. Dans le tableau de la documentation, la transcription audio apparaît sans durée de conservation. Pour le texte, c’est-à-dire les résumés et la recherche, la limite de 30 jours s’applique.
  • Qui y a accès. L’accès à ces données est limité aux employés autorisés et aux prestataires liés par la confidentialité, pour le support technique, l’enquête sur les abus et les obligations légales.
  • Le transfert depuis l’UE. L’accord de traitement des données d’OpenAI repose sur les clauses contractuelles types approuvées par la Commission européenne, ou sur des décisions d’adéquation de la Commission.

Les règles d’OpenAI peuvent changer. Les liens vers les pages officielles sont à la fin.

Mode privé : enregistrement local seulement

Le Mode privé est un seul interrupteur qui coupe tous les appels externes. Lorsqu’il est activé, SageMeet devient un dictaphone local. Vous enregistrez, vous écoutez et vous rangez les réunions, mais rien ne part chez OpenAI ni ailleurs.

Ce que vous perdez : la transcription, les résumés et la recherche par le sens, parce qu’ils dépendent tous d’OpenAI.

Vous activez l’interrupteur dans l’application.

C’est un bon choix pour une réunion que vous voulez garder seulement comme du son.

iCloud n’est pas OpenAI

SageMeet peut synchroniser les réunions en option via iCloud, pour les avoir sur vos autres appareils Apple. C’est un chemin à part, entre le téléphone et votre compte iCloud, géré par Apple. Les données sont chiffrées par Apple en transit et au stockage.

Si vous ne voulez pas non plus que les réunions arrivent dans iCloud, laissez la synchronisation iCloud coupée.

Avant une réunion sensible

Quelques habitudes simples :

  • Dites aux personnes de la réunion que vous enregistrez et, s’il y a lieu, que la transcription passe par OpenAI.
  • Décidez à l’avance si la réunion a besoin d’une transcription. Sinon, activez le Mode privé.
  • Vérifiez le résumé. Il est généré automatiquement. Les noms, les chiffres et les échéances méritent d’être vérifiés dans la transcription ou dans l’enregistrement.
  • Supprimez ce que vous n’utilisez plus. Vous pouvez supprimer un enregistrement, ou toutes les données, à tout moment, dans Réglages.
  • Utilisez une clé d’API dédiée et suivez sa consommation dans le compte OpenAI.

SageMeet est gratuit sur l’App Store. Les détails sont sur la page SageMeet (en anglais), et ce que chaque application conserve est expliqué dans la politique de confidentialité.
